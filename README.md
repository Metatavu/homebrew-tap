# Metatavu Homebrew tap

Formulae for Metatavu's internal tools.

```sh
brew tap Metatavu/tap
brew install metatavu/tap/<tool>
```

One tap for every tool rather than one per tool: users tap once, and formulae in
`Formula/` are independent of each other.

## Access

Both this tap and the tools it installs live in private repositories.

Tapping uses your existing git credentials, so it needs no extra setup. **Downloading a
binary does**, because Homebrew fetches release assets over the API:

```sh
export HOMEBREW_GITHUB_API_TOKEN=$(gh auth token)
```

Put that in your shell profile. Without it Homebrew receives a bare `404` rather than an
authentication error, which is a confusing way to discover the problem.

## Adding a tool

Formulae here are generated by the source repository's release workflow rather than edited by
hand, so a release and its formula cannot drift apart. To add a tool:

1. Have its release workflow build binaries per platform and publish them with `.sha256` files.
2. Give it a step that renders `Formula/<tool>.rb` and pushes it here, using a token with
   write access to this repository.
3. Add a row to the table above.

For private release assets the formula must use
`GitHubPrivateRepositoryReleaseDownloadStrategy`; see `Formula/severa.rb` for a worked example.
